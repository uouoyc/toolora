# 领域词汇表

Toolora 的统一术语表。平台没有账号和历史,只有三个业务上下文:平台本身、关键词排名查询、关键词聚类。代码命名、UI 文案与文档表述都使用这里的词汇;容易误用的同义词在各词条后注明。

## 平台

- **Tool(工具)**:访客无需账号即可独立使用的在线小工具。共享 Toolora 外壳与部分能力,不共享工作流或结果。〔不叫:产品、插件〕
- **Workspace(工作区)**:一个工具在访客浏览器里的当前状态,至多一个,只含一个当前分析,没有历史。〔不叫:项目〕
- **Analysis(分析)**:工作区内一起处理的一组输入。追加输入即扩大当前分析;开始新分析则整体替换。
- **Provider(数据源)**:为工具提供数据的外部服务。当前 SERP 数据源是 SerpAPI。
- **SerpAPI 设置**:使用 SerpAPI 的工具共享的浏览器本地配置,含密钥池及其选择策略(轮询/顺序)。
- **密钥池(Key Pool)**:访客自己提供的 SerpAPI Key 集合,只存在访客浏览器里。〔不叫:平台密钥〕

## 关键词排名查询(`/keyword-ranking`)

- **目标域名(Target Domain)**:要查询排名的精确归一化主机名。忽略前导 `www.`,其余子域名视为不同域名。
- **查询深度(Search Depth)**:每个关键词考察的自然结果数上限,Top 10–50。
- **一次查询(Run)**:浏览器管理的一次完整查询尝试。关闭页面即停止。〔不叫:任务〕
- **Key 亲和(Key Affinity)**:关键词到「上次以 Found/Not Found 完成它的 Key」的私有映射。查询设置变化时保留,永不出现在结果或导出中。
- **地区语言快照**:SerpAPI 官方国家(gl)/语言(hl)列表的固化快照,由 SerpAPI 设置持有。表单只接受快照成员,代码可为多段(如 `zh-cn`)。
- **Found / Not Found / Failed**:目标域名出现在查询深度内并得到可信排名 / 查询成功但目标域名未出现 / 请求或数据源失败导致无可信结果。注意 Not Found 不是失败。

## 关键词聚类(`/keyword-clustering`)

- **SERP 证据(Evidence)**:一个关键词 Top 10 自然结果的归一化完整排名 URL。
- **合并精度(Grouping Accuracy)**:两个关键词属于同一聚类前必须共享的最少完整排名 URL 数(1–10,默认 4)。〔不叫:相似度、置信度〕
- **聚类(Cluster)**:任意两个成员都满足合并精度要求的关键词集合。
- **单例聚类(Singleton Cluster)**:因无法与其他关键词可靠分组而单独成聚的关键词。
- **主关键词(Primary Keyword)**:与同聚类其他成员 URL 重叠总量最大的成员;输入顺序破平局。
- **域名分析(Domain Analysis)**:可选的、以目标域名评估聚类的动作;未填目标域名即不存在。
- **域名匹配(Domain Match)**:主机名精确匹配目标域名且出现在成员 SERP 证据中的 URL。
- **可能的自我竞争(Possible Cannibalization)**:同一聚类的 SERP 证据中出现多个目标域名 URL 的情形。
